## MC Manager v3.0.0

Cross-platform Minecraft server manager. A single bilingual (FR/EN) build per
platform. The language is chosen on first launch and can be changed anytime
with `mc language fr|en`.

A foundations release: the JSON output of every command is now described by an
OpenAPI 3.1 contract (`api/openapi.json`) that the test suite checks against
real `--json` runs, and failures follow one shape everywhere.

Every command with `--json` answers `{"schema":1,"ok":...,"code":...}` and
exits 0 on success, 1 on failure, 2 on an invalid command line and 3 when the
server is unknown.

### Changes for scripts

These changes are visible to anything that parses `--json` output or exit
codes.

- **`mc players --json` on a stopped server is now a failure.** It answers
  `ok:false`, `code:"server_offline"` and exits 1 (it used to answer
  `ok:true` and exit 0). `online` (0), `max` (null), `players` ([]) and
  `state` are still present. Without `--json` the command still prints an
  information line and exits 0.
- **Every failure has a `message`.** The text is localised (FR or EN, as chosen
  with `mc language`); branch on `code`, which is stable and never translated.
  `not_found` always carries `target` and `available` (a list of `id:name`).
- **The nested `error` object is obsolete.** `mc status`, `mc players` and
  `mc active` failures still carry `error: {code, detail}` next to the
  top-level fields for compatibility. Read `code`, `message` and `detail`
  instead; the alias will be removed in a later major version.
- **`mc config get --json`** answers
  `{"ok":true,"code":"config","server":...,"config":{...},"secrets_set":[...]}`.
  Secret settings are not in `config`; `secrets_set` lists their names.
  `mc config get <key> --json` answers `{"code":"config_value","key":...,"value":...,"write_only":false}`;
  a secret key answers `write_only:true` and no `value` unless `--reveal` is
  given. An unset key is `ok:false`, `code:"config_key_unset"`, exit 1.
  Without `--json` the output is unchanged.
- **`mc alert list --json` no longer returns `"***"`.** The `secret`, `token`
  and `password` fields of a channel are gone, not masked. `secrets_set` and
  `header_names` say what is configured.
- **`mc java list <server>`** lists only that server (exit 3 and `not_found`
  for an unknown one) instead of ignoring the argument.

### Download

| File | Platform |
|---|---|
| MCManager.zip | Windows |
| MCManager-Linux.zip | Linux |
| SHA256SUMS, SHA256SUMS.sig | Signed hashes of both packages |

### Installation
- Windows: extract the zip, then run install.bat as administrator.
- Linux: extract the zip, then run ./install.sh as root (sudo).

On the first `mc` command you will be asked to choose your language.
