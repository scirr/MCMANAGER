## MC Manager v3.0.1

Fix release for 3.0.0.

### Fixed

- Updating from 2.4.8 with `mc update` left an installation that no longer
  started (`ModuleNotFoundError: mc_api`): the old updater copies files one by
  one and stopped on the folder holding the Linux desktop app. The Linux zip is
  now flat, the app is the single file `mcmanager-app`, and `mc update` keeps it
  up to date. If you already updated from 2.4.8 and `mc` fails, extract
  `MCManager-Linux.zip` and run `sudo ./install.sh` again: your servers and
  settings are kept.
- Updating from 2.11 with `mc update` now also installs the Linux desktop app.

Everything else is as in [3.0.0](v3.0.0.md), whose notes describe the new
features.

### Download

| File | Platform |
|---|---|
| MCManager-Setup.exe | Windows: installer (embedded Python, service, desktop app, Start menu shortcut) |
| MCManager.zip | Windows: manual install with `install.bat`; the package `mc update` uses |
| mcmanager_3.0.1_all.deb | Debian, Ubuntu: command line, daemon and desktop app |
| mcmanager-3.0.1-1.noarch.rpm | Fedora: command line, daemon and desktop app |
| MCManager-Linux.zip | Linux: manual install with `install.sh`, desktop app included as the single file `mcmanager-app` |
| MCManager-macOS.zip | macOS: command line and daemon (`install.sh`) |
| MCManager-App-macOS.zip | macOS: the desktop app, `MCManager.app` |
| SHA256SUMS, SHA256SUMS.sig | Signed hashes of every file above |

### Installation

- Windows: run `MCManager-Setup.exe`. It installs everything (no Python needed),
  starts the service and adds the app to the Start menu. Servers and worlds live in
  `C:\ProgramData\MCManager` and are never touched by the uninstaller. The installer
  is not code-signed yet: Windows SmartScreen shows "Windows protected your PC";
  choose More info, then Run anyway. Without the installer: extract
  `MCManager.zip`, then run `install.bat` as administrator (needs Python 3.10+).
- Linux: `sudo apt install ./mcmanager_3.0.1_all.deb` (or `sudo dnf install
  ./mcmanager-3.0.1-1.noarch.rpm`), then `sudo mcmanager-setup <user>`. The desktop
  app (`mcmanager-app`, menu entry "MC Manager") needs GTK 4 and libadwaita:
  they are recommended packages, installed by default. Without a package:
  extract `MCManager-Linux.zip`, run `./install.sh` as root; the app is `./mcmanager-app`.
- macOS: extract `MCManager-macOS.zip`, run `./install.sh` as your user (not with
  sudo). For the desktop app, unzip `MCManager-App-macOS.zip` and move
  `MCManager.app` to Applications. The app is not signed: on the first launch,
  right-click it, choose Open, then confirm (or allow it in System Settings,
  Privacy & Security).

Every file is signed in `SHA256SUMS` (Ed25519, checked by `mc update`) and carries a
build provenance attestation. `mc update` only replaces the core package of its
platform; the Windows installer, the packages and the app are updated by installing
the new version.

On the first `mc` command you will be asked to choose your language.
