## MC Manager v2.6.0

Cross-platform Minecraft server manager. A single bilingual (FR/EN) build per
platform. The language is chosen on first launch and can be changed anytime
with `mc language fr|en`.

This release brings sleep mode, server switching, and datapack and mod
management. Every operation now goes through one internal layer that returns
structured results, so the command line and a future graphical interface
behave exactly alike. The new commands are Linux-only for now; the Windows
build is unchanged apart from the version number.

### New (Linux)

- **Sleep mode** - `mc sleep enable --after 2h`. When nobody has played for
  that long, the server is saved and stopped, and its memory is freed. The
  service then holds the game port: the server stays visible in the
  multiplayer list ("sleeping", 0 players, compatible with every game
  version) and wakes up when a player it already knows tries to join.
  Unknown names (mostly internet scanners) get a polite refusal and never
  wake it. It never wakes during a world freeze, outside opening hours, or
  after a manual `mc stop`. Also: `mc sleep status`, `mc sleep wake`,
  `mc sleep allow|deny <player>`. `mc status` shows the state `sleeping`.
- **`mc switch <server>`** - hands the active server's place to another
  one: refuses while players are online (`--force` to override), stops the
  current server and waits for its process to exit, swaps the game ports and
  the RCON ports (a shared RCON port is replaced by a free one), updates both
  `server.properties`, then starts the new server. Players keep the same
  address.
- **`mc datapack list|enable|disable`** - live management with ordering
  (`--before`, `--after`, `--first`, `--last`). Flags packs placed in a
  sub-folder (ignored by Minecraft), says when a pack changes world
  generation and needs a restart, and moves already enabled packs (which
  Minecraft itself refuses to do).
- **`mc mod list|add|remove`** - handles both copies when AutoModpack is
  used (`mods/` and the host modpack), so a removed mod is no longer shipped
  to players; `--server-only` keeps a mod off the modpack. Removal moves
  files to `mods_quarantine/<date>/` instead of deleting them, and a mod that
  adds blocks is only removed with `--yes` (its blocks turn into air in the
  world).
- **Starting goes through the service.** `mc start`, `mc switch` and
  wake-ups are carried out by the service whenever it runs: a server is
  never a child of your terminal, so it stays inside the service's memory
  and swap limits. Without the service, `mc start` still works and says so.
- **`--json` on every new command**, returning `{"ok", "code", ...}` with
  stable codes.

### Improved

- `mc config set` refuses a port already used by another server as a game
  **or** RCON port.
- `mc doctor` warns when two servers declare the same RCON port.

### Deprecated (still working)

- **External sleep tools** that stop the server themselves and hold its
  port. Use `mc sleep enable`. A server stopped that way (maintenance flag
  without `stop_reason`) is shown as `stopped-by-user` and is never woken by
  MC Manager, so both can coexist during a migration - but only one of them
  may hold the port: disable the external tool before enabling sleep mode.
- **Switching servers by hand** (maintenance flags, port edits in
  `config.json` and `server.properties`). Use `mc switch`.

Nothing is removed. `servers.json` and `config.json` keep their keys; the new
settings (`sleep_enabled`, `sleep_after`, `sleep_allow`) are optional.

### Updating

`mc update`, and that's it: this release does not change the systemd unit, so
`sudo ./install.sh` is not required (`mc update` checks it). The service is
restarted by the update; running servers are not stopped. If an external
tool currently holds a sleeping server's port, stop that tool before
`mc sleep enable`.

### Installation
- Windows: extract the zip, then run install.bat as administrator.
- Linux: extract the zip, then run ./install.sh as root (sudo).

On the first `mc` command you will be asked to choose your language.
